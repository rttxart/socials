# socials · öffentlicher Medien-Host für Buffer

Buffer nimmt Bilder und Videos nur als öffentliche URL an, nicht als lokale Datei. Dieses Repo liefert diese URLs, damit Posts als vollständige Buffer-Entwürfe angelegt werden können.

- Nur Medien, die zur Veröffentlichung freigegeben sind (Robert-Abnahme und Paul PASS). Keine internen Daten, keine Entwürfe, keine Kundendaten.
- Struktur: `<YYYY-MM-DD>-<profil>-<slug>/<datei>`
- Raw-URL: `https://raw.githubusercontent.com/rttxart/socials/main/<ordner>/<datei>`
